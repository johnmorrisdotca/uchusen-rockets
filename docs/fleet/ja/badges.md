# 艦隊のバッジ

艦隊全体の紋章がひとつ、各艦の丸い家紋風のクレストがひとつずつ、ロムルス級の級章がひとつ、各艦の乗組員パッチがひとつずつあります。どれも、このパッケージのために手で描いた平らなSVGで、艦隊の色だけで描いてあり、16pxから512pxまでくっきり見えます。英語版は [../badges.md](../badges.md) です。

- 絵：`src/data/fleet/badges/*.svg`（このファイルが元です）
- データと関数：`src/data/fleet/badges.ts`（`FLEET_BADGES`、`FLEET_BADGE_SHIPS`、`badge`、`badgesOf`、`badgeSvg`、`badgeUri`）
- テスト：`test/fleet-badges.test.ts` と `e2e/fleet-badges.demo.ts`

艦のモデルには手を入れていません。バッジは、あとで各艦にデカールとして貼ります。

## バッジの一覧

| ID | 種類 | 艦 | デザイン |
|---|---|---|---|
| `fleet-emblem` | 紋章 | 艦隊全体 | 輪の中に、傾いた軌道と四つ角の星。下の板に小さく SPX。 |
| `crest-kaminari` | クレスト | 加美鳴 (かみなり) SPX-207 | 輪を破る一本のいなずま。 |
| `crest-miyamoto` | クレスト | 宮本 SPX-452 | 鳥居と、交差した二本の剣。 |
| `crest-ariake` | クレスト | 有明 (ありあけ) SPX-186 | 水平線の三日月と、うしろの朝日の光。 |
| `crest-hanabusa` | クレスト | 花房 | 丸くまとまった七つの花。 |
| `class-romurusu` | 級章 | ロムルス級（宮本・有明） | 六角形の中の、正面を向いたオオカミの顔。 |
| `patch-*` | 乗組員パッチ | 各艦に一つ | 盾の形に、クレスト、上に艦名、下に登録番号。 |

紋章は艦隊だけのもので、SPXのマークではありません。マークは使わず、まねもしていません。板の上の小さな SPX は、運用者の名前を文字にしたものです。

## 作り方

- **家紋風。** 丸い輪と、ひとつの平らな図柄だけ。グラデーションも影も細い線もありません。
- **二色か三色＋ふち。** ふちと地は暗い `heatSink`、輪は明るい `protected`、そこに `FLEET_PALETTE` の色を一つか二つ足します。暗い船体でも白い毛布の上でも、同じ絵が見えます。
- **文字は線です。** 文字は `scripts/badge-letters.ts` で描いた線で、フォントはいりません。SVGに日本語は入れていません。漢字の名前と読みは `FLEET_BADGE_SHIPS` にあります。
- **公開してよい言葉だけ。** 艦名、登録番号、級の名前だけです。番号の説明も、漢字の説明もしません。
- **サイズの上限。** クレスト・紋章・級章は4KB以下、パッチは6KB以下、全部で24KB以下です。

## 使い方と直し方

英語版の「Using one」と「Changing a badge」を見てください。SVGを直したら `pnpm badges` を実行します。

**花房の登録番号は、まだ決まっていません。** `HANABUSA_REGISTRY` は仮の値で、パッチには番号の代わりに SPX と描いてあります。番号が決まったら、定数を直して、パッチの下の行を描き直します。
